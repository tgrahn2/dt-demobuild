Integrations 11
VIN decode BFF
NHTSA vPIC · vpic.nhtsa.dot.gov/api
Server-side from the SFNext BFF (/action/vin-lookup) — no SCAPI/cartridge. VIN → year / make / model.
Fitment lookup SCAPI
wheel-size.com · api.wheel-size.com/v2
Vehicle → OE tire size via /custom/fitment/v1. Vendor-neutral → Treadwell.
Fleet portal SSO core SCAPI
SLAS external IdP · OIDC + PKCE
Core org is the IdP; loginMergeClaims: email links the B2C shopper.
Real-time credit check core SCAPI
Apex REST · /services/apexrest/fleet-credit
Pre-createOrder PO credit check in the core org. Fail-soft.
Quote → order / price-match core SCAPI
/custom/quote/v1 · core /services/apexrest/quotes
SCAPI locks per-line prices on the basket; quote + case records live in core CRM.
Appointments core SCAPI
Salesforce Scheduler · /services/apexrest/appointments
Books + reads installs on ServiceAppointment (email-scoped).
Order Management (OMS) core SCAPI
Salesforce OMS · OrderSummary · /order-status
Orders flow into OMS for fulfillment & lifecycle; storefront reads authoritative status.
Agent → Service Cloud handoff core
Agentforce Connected App (JWT) · Omni-Channel
"Transfer to a human" routes the live chat into Service Cloud with full context.
B2C ↔ CRM identity link core SCAPI
Person Account · PersonEmail · loginMergeClaims: email
Unifies the B2C shopper with the core Person Account by email.
eProcurement PunchOut SCAPI
cXML PunchOutOrderMessage · /custom/order/v1
Tire Rack — SAP Ariba punch-out → cXML requisition → approved PO → intake API → real B2C order.
Dealer contract pricing SCAPI
Shopper Context · c_tireRackDealerId → accountOrgId
Tire Rack — dealer slug → accountOrgId Shopper Context qualifier; activates the dealer price book on PLP/PDP/cart.

Custom objects 2
dtGarage
garageKey · data (JSON) · orgName
A shopper's vehicles + household as one JSON blob. Keyed by customerId (retail) or c_fleetOrgId (fleet). Read/written via the custom fitment API.
dealerPortalConfig
dealerId (key) · data (JSON) · updatedBy
Tire Rack — a dealer's self-service portal config (branding, home content, catalog price edits) as one JSON blob, keyed by dealer slug. Edited in the "mini-BM" admin console via /custom/dealer-config/v1; merged over the static seed by the storefront.

Tools

The tools we used


Storefront Next
Headless storefront framework. One SFNext app serves retail and fleet.
  • React Router v7 — SSR, file-based routes, server loaders/actions
  • Vite build + TypeScript (strict, no .js in src)
  • Tailwind + shadcn / Radix UI primitives, token-driven theming
  • Adapter pattern over typed SCAPI clients
  • Extensions system + Page Designer integration
  • Storybook for component dev, snapshot & a11y tests
  • Agentic-ready: CLAUDE.md + docs/README-*.md give AI agents full context
github.com/SalesforceCommerceCloud/storefront-next-template ↗
SCAPI — Commerce APIs

The B2C Commerce API layer.
Shopper APIs (SLAS auth, products, search, baskets, orders) power the storefront;

Admin APIs (catalogs, Page Designer, site data) back tooling & config. Our /custom/* endpoints extend both — every integration rides typed SCAPI contracts. developer.salesforce.com ↗
B2C Agentic Developer Toolkit
One agentic MCP across the whole B2C platform
  • Storefront Next dev — primarily used in this demo
  • Headless dev — Not planning to use our 'head' - no problem, build your own
  • DevOps — cartridge deploy (WebDAV), code versions, log tail, remote debugger
  • Catalog & data — Admin APIs for catalogs, products, Page Designer (or your existing CMS), site data / impex
  • Analytics — Commerce Intelligence (CIP) queries + metrics
  • Docs & skills — curated skills + docs that guide agentic workflows
salesforcecommercecloud.github.io/b2c-developer-tooling ↗
Frontier LLM (coding agent)
AI pair-programmer. Built the extensions, custom APIs, and this deck. Model-agnostic — Claude, Gemini, or any frontier LLM.
Figma
Design-to-code. Via the Figma MCP: Page Designer blocks, My Vehicles, and the loyalty page went design → React. figma.com ↗
Managed Runtime (MRT)
Salesforce hosting for headless. The SFNext bundle deploys here as a Node SSR app on Salesforce's edge/CDN. developer.salesforce.com ↗
Agentforce
Conversational agent platform. The shopper agent and the transfer-to-human handoff into Service Cloud (Omni-Channel). salesforce.com/agentforce ↗
